# Эскиз PRO

Внутренний инструмент экосистемы **РЕцепт PRO** для оформления технических эскизов поверх готовых изображений из PRO100.

## Возможности первой версии

- загрузка JPG, PNG и WEBP без изменения исходного изображения;
- панорамирование, масштабирование и режим «по размеру экрана»;
- свободные, горизонтальные и вертикальные технические размеры с трёхэтапным построением A → B → отступ;
- цепочки на общей базовой линии с общим отступом и быстрым вводом каждого значения;
- префиксы, допуски, примечания, скрытие единиц и положение текста размеров;
- привязка к концам и направляющим существующих объектов;
- автоматическая нумерация модулей М01, М02…;
- комментарии, выноски, техника и ссылки;
- независимый слой аннотаций, редактирование, перемещение и изменение рамок объектов;
- автоматические или вручную заданные размеры рамок модулей, комментариев, техники и ссылок;
- дублирование, удаление, undo/redo и горячие клавиши;
- настраиваемая информационная шапка;
- локальное сохранение проектов в IndexedDB;
- переносимые файлы `.eskiz` с изображением и всеми объектами;
- локальная история до 12 контрольных точек и автоматические резервные копии;
- установка как PWA и работа без интернета после первого открытия;
- экспорт PNG и PDF, включая кликабельные ссылки в PDF.

## Запуск

```bash
npm install
npm run dev
```

Сборка production-версии:

```bash
npm run build
npm run preview
```

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `V` | Курсор |
| `Q` | Повторить последний инструмент |
| `A` | Опорная точка |
| `R` | Свободный размер под любым углом |
| `H` / `J` | Горизонтальный / вертикальный размер |
| `Shift` при свободном размере | Привязка угла к 0°/45°/90° |
| `Alt` при создании/редактировании | Временно отключить привязки |
| `Enter` / `Tab` после размера | Принять значение / принять и повторить инструмент |
| `C` | Цепочка размеров |
| `M` | Модуль |
| `L` | Выноска |
| `T` | Комментарий |
| `E` | Техника |
| `K` | Ссылка |
| `Ctrl/Cmd + Z` | Отмена |
| `Ctrl/Cmd + Shift + Z` | Возврат |
| `Ctrl/Cmd + D` | Дублировать |
| `Ctrl/Cmd + C / V` | Копировать / вставить, включая другой проект |
| `Shift + клик` | Добавить объект к выделению |
| `Drag` по пустому месту | Выделить объекты рамкой |
| `Ctrl/Cmd + S` | Сохранить |
| `Delete` | Удалить |
| `Стрелки` / `Shift + стрелки` | Сдвинуть объект на 1 / 10 пикселей |
| `Пробел + drag` | Перемещение рабочего поля |
| `Ctrl/Cmd + колесо` | Масштаб |

Подробное архитектурное решение: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
